# Contributing to Lensmor open source

Thanks for your interest in contributing! Lensmor maintains a set of open
resources for the trade show and B2B events community — curated lists, open
datasets, templates, and free tools. Community contributions keep them accurate
and useful.

## Ways to contribute

- **Add or correct data** — e.g. a missing trade show in
  [trade-show-calendar](https://github.com/LensmorOfficial/trade-show-calendar)
  or a new entry for
  [awesome-trade-shows](https://github.com/LensmorOfficial/awesome-trade-shows).
- **Improve templates & playbooks** — sharper copy for the email/LinkedIn
  templates or the exhibitor intelligence playbook.
- **Report bugs or suggest ideas** — open an issue in the relevant repo.

## How to submit a change

1. Fork the repository and create a branch from `main`.
2. Make your change. Keep it focused — one topic per pull request.
3. For data contributions, follow the existing file format (CSV/JSON/Markdown)
   and include a source link where possible.
4. Open a pull request describing **what** changed and **why**.

## Guidelines

- Be accurate. For trade show data, cite an official event page or organizer.
- Keep formatting consistent with the surrounding content.
- One logical change per PR makes review faster.
- By contributing, you agree your contribution is licensed under the
  repository's existing license.

## Questions

Open an issue, or email **hello@lensmor.com**.
