# Getting help

For an open-source resource, use the issue chooser in the repository where you found the problem. Include a page or file link, what you expected, and what happened. For event corrections, include the organizer's official source and the edition year.

For Lensmor product, API account, billing, or subscription questions, visit the [Help Center](https://help.lensmor.com/) or email [hello@lensmor.com](mailto:hello@lensmor.com).

Do not post API keys, customer contact lists, private account details, or unredacted logs in public issues. Report security-sensitive problems using [SECURITY.md](SECURITY.md).
